# abisoye-portfolio-website

Personal portfolio of **Oyindamola Caleb Abisoye** — mobile developer (React Native / Flutter), manual QA tester, and founder at Brivent Global.

A single static page: `index.html` + `style.css` + `script.js`. No build step, no dependencies.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## Easter egg

Press **Q** (or the **Run QA** button in the nav, or add `?qa=1` to the URL) to overlay QA annotations on the page.

## Deploy

Works as-is on GitHub Pages: repo **Settings → Pages → Deploy from a branch → `main` / root**.
